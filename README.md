# Fluent Swap Android

Android-клиент Fluent Swap: мгновенный подбор языкового партнёра и временный
текстовый чат поверх WebSocket API `fluent-swap-core`.

Проект готовится как Android submission для RevenueCat Shipaton 2026. MVP:

`language selection → matchmaking → room → text chat`
